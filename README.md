# Student-Report-Card--Python-GUI-Project

A simple Python program that generates a student's report card using pop-up windows.

No terminal typing needed. Just like Java's "JOptionPane" , all input and output happens in popup boxes.

## Features
-**GUI Popups**: Takes Student Name , Subjects , and marks using easygui popups.

-**Auto Calculation**: Calculates Total , Average , and Grade automatically.

-**Grading System**: A = 80-100 , B = 60-79 , C = 41-59 , Fail =Below 40

-**Final Result Box**: Show complete report card in one popup.

-**Beginner Friendly**: Only 1 Library needed

##Teck Stack 

-**Language**: Python 3

-**Library** : easygui
